## 素材の扱い

- ヒーロー・宣言・お客様紹介の採用画像は、画素を変更せず可逆WebPへ変換しています。`assets/provenance.json` に出典画像のハッシュと一致確認を記録しています。
- ヒーローは画像生成で作成・選定されたv9デザインです。「画素一致」は承認済みデザインとの一致を指し、人物の実写真原本との一致を意味しません。
- 表示範囲はv9のヘッダーがy=0〜135、コピー・写真がy=136〜1321、固定CTAがy=1690〜1841です。v11宣言画像は全体を表示します。
- メイン画像内の旧宣言と旧CTAはCSSの表示範囲で除外し、新しい宣言を重ねて二重表示しません。既存CTAの意匠は固定ボタンで再利用します。
- お客様紹介の見出しは採用画像を使用。カードは実際に動くHTMLです。お客様の写真はユーザー提供の公式Instagram投稿スクリーンショット原本を使い、Instagram画面のUI部分のみCSSで表示範囲外にしています。人物の再生成や肌・体型の変更はしていません。
- 美容整形ちゃん様（2024-04-27）、モデルのお客様（2024-03-22）、安藤社長様（2023-11-24）の表記・施術内容は提供投稿の本文に基づきます。架空の口コミや推薦コメントは追加していません。
