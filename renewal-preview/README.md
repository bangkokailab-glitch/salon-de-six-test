# Salon de Six — トップページ冒頭の確認用実装

公開先: https://bangkokailab-glitch.github.io/salon-de-six-test/renewal-preview/

## 2026-10-27 採用B案・モーション仕様

ユーザーが選択したB案を採用。人物とメインコピーは文書とともに通常スクロールし、人物を除いた店内写真だけを画面に固定します。冒頭の背景は鮮明に保ち、宣言パネルを読み進めると同じ店内写真のぼかし層が徐々に重なります。背景の位置自体は動かしません。

- スマホの初期ファーストビューに「顧客満足度No.1宣言」「総来店客数2,000人超え」「創業4年」「日本語対応」まで表示。
- 深緑・金の宣言パネルは、上部をコンパクトにした窓と下部を等倍で見せる窓に分けて連続表示。統計の直後で枠を閉じず、固定LINEボタンの背面から下へ4つの宣言が続きます。
- メインコピーはロード時に順次フェードイン。宣言内のタイトルは文字ごとに表示し、No.1を続けて強調。お客様紹介の見出しもスクロールに合わせて表示。
- 総来店客数は1→2,000、創業年数は1→4。統計が固定CTAより上に出てから一度だけ開始。
- LINE CTAは透明背景の切り抜き。6pxの上下浮遊。リンクは従来どおり https://lin.ee/7VR8UlP 。
- ヘッダーは「電話する」「メニュー」。電話番号は従来どおり +66 98-391-8717。
- お客様紹介の横スワイプ・左右ボタン・ドット・サムネイル・左右キーは従来どおり。自動送りなし。
- 動きを減らすOS設定では文字演出・カウントアップ・CTA浮遊を停止。JavaScript無効時も文章と最終数値を表示。

## 素材

- B案の新しい店内背景・人物切り抜き・メインタイトルは、B案の原画を元にimagegenで分離編集した素材です。原画と同一画素の単純な切り出しではありません。
- 使用ファイルは `salon-background-b.webp`、`people-b-cutout.webp`、`hero-title-b.webp`。`assets/b-motion-provenance.json` は分離編集後の素材と配信用WebPとの可逆変換による画素一致を記録しており、B案の原画との画素一致を意味しません。
- 既存v13のLINE切り抜き、文字なしの金枠・王冠パネル、お客様紹介の見出し枠を再利用。枠外を透明にして固定の店内背景を見せています。
- `assets/motion-provenance.json` は再利用しているv13の編集済み素材と配信用WebPの画素一致を記録。元の承認済み画像と編集済み装飾の画素一致を意味しません。
- `hero-approved.webp` は承認済みヘッダー部分に使用。旧宣言・旧CTA・旧人物写真部分は表示しません。
- お客様の写真はユーザー提供の公式Instagram投稿スクリーンショット原本。InstagramのUIだけCSS表示範囲外にし、人物を編集していません。
- 美容整形ちゃん様（2024-04-27）、モデルのお客様（2024-03-22）、安藤社長様（2023-11-24）の表記・施術内容は提供投稿の本文に基づきます。架空の口コミは追加していません。
- 出典リンクは公式Instagramプロフィール。個別投稿URLは未確認のため作成していません。

## 範囲と復元

反映対象はテスト用GitHubリポジトリ `salon-de-six-test` の確認ページ `renewal-preview/` のみです。既存男磨きLP、サロン本番サイト、DesignNOW、main、Pagesワークフローは変更対象外。検索除外メタタグを維持し、計測タグは設置していません。

No.1宣言・来店数・創業年数は承認済みユーザー指定文言で、独自調査認定を示すものではありません。

ローカル確認: リポジトリルートで `python3 -m http.server 8878` を実行し、`http://localhost:8878/renewal-preview/` を開く。ビルドや外部アニメーションライブラリは不要。
