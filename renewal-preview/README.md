## 現在の採用版: 2026-10-28

対象は `renewal-preview/` のみ。ユーザーの「既存の確認用ページを更新」という承認に基づく更新です。本番サイト、既存の男磨きLP、main、配信設定、計測タグは変更していません。

### ページ構成

1. 承認済みヘッダー + C案のメイン画像（画像を再生成せずWebP化）
2. サロンの紹介: リボンH2、店内写真、HTML本文

5. 店舗情報: 店舗写真、Googleマップ、住所、営業時間、Salon de Sixについて

トップ本文には独立した料金・FAQ・来店の流れ・お客様の声・口コミ・No.1宣言の各セクションを置いていません。No.1宣言と実績の表現は、承認済みメイン画像内の表示を維持しています。

### 動きと操作

- サービスは手動送りのみ。スワイプ、矢印、サムネイル、ドット、左右キー/Home/Endに対応。
- 動画は操作前にプレーヤーを読み込まず、再生操作後だけYouTube privacy-enhanced iframeを読み込みます。スライド変更時に前の動画を停止します。
- メニューはモーダル。Escape、閉じるボタン、背景クリックで閉じ、元のボタンにフォーカスを戻します。
- 下部クーポンCTAはメイン画像内CTAが画面の上へ消えてから表示。キーボードで選択中のリンクが隠れないようスクロール位置を調整。
- 本文・リボン・写真に控えめなスクロールフェード。`prefers-reduced-motion` では動きを停止。
- 写真は16:9、Instagramは1:1で表示。メイン画像・ヘッダーは承認原画の比率を維持。
- 外部アニメーションライブラリ、広告CVタグ、アクセス解析は読み込みません。検索除外メタを維持。

### 素材・復元

現行アセットは `assets/home-20261028/`。`asset-manifest.json` に原素材名・切り抜き範囲・出力サイズ・SHA256を記録しています。WebPは画質指定の非可逆圧縮であり、原画像と画素が完全一致するという意味ではありません。人物・文言・構成は再生成していません。

旧版の画像・スクリプトは復元用に保持し、現行HTMLから読み込みません。変更前のgh-pagesコミットは `7714cadf0efa69f7ef20136d44d64e5532837d3e`。

ビルド不要。`index.html` をブラウザーで開くか、リポジトリルートで `python3 -m http.server 8769` を実行して `/renewal-preview/` を確認できます。

## 素材

- B案の新しい店内背景・人物切り抜き・メインタイトルは、B案の原画を元にimagegenで分離編集した素材です。原画と同一画素の単純な切り出しではありません。
- 使用ファイルは `salon-background-b.webp`、`people-b-cutout.webp`、`hero-title-b.webp`。`assets/b-motion-provenance.json` は分離編集後の素材と配信用WebPとの可逆変換による画素一致を記録しており、B案の原画との画素一致を意味しません。
- 既存v13のLINE切り抜き、文字なしの金枠・王冠パネル、お客様紹介の見出し枠を再利用。枠外を透明にして固定の店内背景を見せています。
- `assets/motion-provenance.json` は再利用しているv13の編集済み素材と配信用WebPの画素一致を記録。元の承認済み画像と編集済み装飾の画素一致を意味しません。
- `hero-approved.webp` は承認済みヘッダー部分に使用。旧宣言・旧CTA・旧人物写真部分は表示しません。
- お客様の写真はユーザー提供の公式Instagram投稿スクリーンショット原本。InstagramのUIだけCSS表示範囲外にし、人物を編集していません。

- 出典リンクは公式Instagramプロフィール。個別投稿URLは未確認のため作成していません。
