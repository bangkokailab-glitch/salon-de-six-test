Client-facing GitHub preview for three first-view directions. Public proposal labels map to the implementation folders as follows:

- A → `/d/` — cinematic action-dock direction
- B → `/a/` — balanced company-benefit direction

All CTA links are proposal-stage placeholders (`#document-request` and `#education-video`). Replace them before production use.

The ten-second background motion files are provisional animations created from the current approved photo. Replace them with the supplied promotional video during production.
